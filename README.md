# João Roim — Portfólio

Site estático de direção de arte e design.

## Como ver localmente

```bash
# Na pasta do projeto
python3 -m http.server 8000
```

Abra http://localhost:8000

## GitHub Pages

1. Crie um repositório novo no GitHub.
2. Envie estes arquivos para a raiz do repositório (`index.html` precisa ficar na raiz).
3. Em Settings → Pages, escolha a branch `main` e a pasta `/ (root)`.
4. O site fica em `https://<usuario>.github.io/<repositorio>/`.
